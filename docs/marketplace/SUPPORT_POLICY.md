# Support policy (DRAFT)

- Channel: <support portal or email to be set by the vendor>.
- Hours and response: first response within 1 business day (Marketplace expects commercially reasonable support; Atlassian-listed apps
  commonly commit to 24-hour, 5-day response for critical tickets, verify current requirements before publishing).
- Severity: S1 data exposure or total outage; S2 major feature broken; S3 degraded; S4 question.
- Customer must provide: site URL, app version, time of occurrence, steps. Support will never ask for protected content or API tokens.
- Supported versions: latest release. Cloud only.
- Escalation: S1 treated as security incident (see VULNERABILITY_DISCLOSURE.md).
