# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep feedback about the code and not the person, and do not harass or
discriminate. Maintainers may edit, reject or remove contributions and block people who do not follow these rules.

Report conduct problems privately to the maintainer through the contact options on the
[@ianido GitHub profile](https://github.com/ianido).
