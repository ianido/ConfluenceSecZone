# Security policy

## Reporting a vulnerability

Please do **not** open a public issue or pull request for security problems.

Report privately through GitHub: [Report a vulnerability](https://github.com/ianido/ConfluenceSecZone/security/advisories/new).
Include the affected version or commit, steps to reproduce and the impact. Do not include real customer data.

Targets: acknowledgement within 3 business days, triage within 7. Fixes ship as a new version and are credited to
the reporter if desired. Test only on your own development site, never on someone else's.

## Supported versions

Only the latest commit on `main` is supported while the project is an internal test candidate.

## Scope

The security model is documented in [docs/SECURITY.md](docs/SECURITY.md).
